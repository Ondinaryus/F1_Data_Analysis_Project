# Core data reconstruction

The pipeline reads the original `gunay-ozsoy/F1_Data_Analysis_Project` raw CSVs at commit `7e0fc6dbecba19e0a95f9f85c1cbd493821f3788`. Run `python scripts/rebuild_recovery_data.py --group core --output /path/to/output`. The output manifest records input hashes, output hashes, fields, sizes, row counts and coverage. The analytical calendar contains races with recorded results, from 1950-05-13 through 2024-07-07; the original calendar is not modified.

`v_summary_base` and `stg_race_result` retain one row per result entry, including historical shared cars and repeated driver entries. `v_grid_start_facts` retains eligible entries with a positive known grid only: nonstarts and grid 0 (unknown or pit-lane position) are excluded from positional comparisons; shared-car rows remain. Summary and grid contracts do not expose resultId, so identical-looking rows can be legitimate. Winner flags reflect positionOrder = 1; constructor race wins must count distinct winning race IDs, not driver winner rows. The grid source's `car_key` combines race, constructor and car number; missing numbers use a driver-based fallback. Race labels use `year | race_name | raceId`, preserving doubleheaders at a circuit.

`team_details` and `track_information` are raw dimension snapshots. `stg_race_schedule` is one row per completed race. `stg_constructor_performance` is one row per official constructor result; `stg_constructor_rankings` and `stg_driver_rankings` retain official cumulative standings, and constructor race points come from official constructor results. No cumulative points are recalculated. `stg_race_result.seconds` is recorded milliseconds divided by 1000; missing durations remain empty.

`v_dnf_by_circuit_year_reason` is one row per race. Starts means recorded entries excluding nonstarts; finishes and disqualifications are separate, and DNF combines recorded incident/health, vehicle/component and other nonfinish outcomes. Status 54 (Withdrew) is nonstart only for zero laps; positive-lap withdrawals are other DNFs. Status 81 (Did not qualify) remains a nonstart even for anomalous resultId 13547, raceId 553, driverId 268 with 9 recorded laps; this contradiction is flagged in the manifest without changing the raw record. Status 96 (Excluded) is regulatory/disqualified. Incident/health is a status category, not a claim of driver fault. Counts describe recorded entries rather than deduplicated cars. The source includes `dnf_other` and `nonstart_count` to make the reconciliation explicit. Definitions are reconstructed for this report, not recovered original formulas.
