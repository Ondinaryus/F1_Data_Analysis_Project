# Timing and circuit metrics

These are reconstructed descriptive metrics, not the original report formulas or measures of entertainment, driver skill, or mechanical reliability. The snapshot ends 2024-07-07. Race keys use year, race name and race ID, so doubleheaders remain distinct.

- Pit statistics describe recorded pit durations, not stationary tyre-change times. Each stop is joined once to an unambiguous race/driver constructor. No outliers are removed. IQR uses linearly interpolated quartiles and standard deviation is population SD.
- Lap times retain recorded milliseconds. Scheduled UTC start and cumulative lap timestamp are available only when a start time is recorded; timestamps are estimates. Compare lap curves on lap number and select a single race.
- The sprint dataset uses actual sprint results. The ordinary race dataset excludes only races named Indianapolis 500; it retains modern United States Grands Prix at Indianapolis. Eligible entries exclude nonstarts. For each race, field size is the maximum of eligible entries, largest positive grid and two. Chaos is mean absolute grid-to-classified-finish movement divided by field size minus one; it does not measure overtakes. DNF is DNF/eligible entries; surprise is (winner grid minus one)/(field size minus one), missing if winner grid is unknown; density is lead-lap finishers/all classified finishers. Each component is clipped to 0–1, and the score is the mean of available components. These are observed dynamics proxies.
- Circuit altitude bands are Low below 250 m, Medium from 250 to below 1000 m, High at or above 1000 m, and Unknown when absent. Mean track speed uses available positive fastest-lap speed samples, whose coverage is limited. Volatility is 100 times DNF/eligible entries and should be labelled DNF rate. Missing speed and rates stay null.
- `config/circuit_types.json` preserves circuit IDs, refs, citations, confidence and notes from the researched lookup. Types describe the most recent F1 configuration, not all historic layouts. Ambiguous raw circuit 44 is Unknown; missing mappings are Unknown.
